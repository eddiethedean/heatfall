# Heatfall support

Heatfall is maintained as an open-source project. Support is provided through
GitHub Issues; there is no guaranteed response time or paid support service.

## Before opening an issue

1. Check the [troubleshooting guide](https://heatfall.readthedocs.io/en/latest/troubleshooting.html).
2. Upgrade to the latest Heatfall release, or include the version where the
   problem occurs.
3. Reduce the problem to a small coordinate sample and a short script. Use
   synthetic coordinates if your source data is private.

## Ask for help or report a bug

Open an [issue on GitHub](https://github.com/eddiethedean/heatfall/issues).
Include the Python and Heatfall versions, operating system, grid and precision,
palette, expected result, and full traceback or a small screenshot as relevant.
Say whether the issue also occurs with map tiles disabled. Do not post personal,
confidential, or sensitive location data.

Feature requests are welcome as issues. Describe the use case and the result you
need; an issue does not imply a delivery date.

## Security reports

Do not disclose vulnerabilities in a public issue. Use the private reporting
route in the repository's [security policy](https://github.com/eddiethedean/heatfall/blob/main/SECURITY.md).
