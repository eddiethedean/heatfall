# Security

Heatfall processes coordinate lists locally and does not send them to a
Heatfall-hosted service. A configured map tile provider may receive requests
that reveal the area being rendered; see [Architecture](architecture.md) and
[Basemaps and output](basemaps.md).

## Report a vulnerability

Please do not report vulnerabilities in a public issue. Use the **Report a
vulnerability** option on the [Heatfall Security tab](https://github.com/eddiethedean/heatfall/security).
Private vulnerability reporting is enabled for this repository. Include the
affected version, steps to reproduce, impact, and any mitigation you know.
Avoid sending real personal location data.

Maintainers will coordinate a fix and disclosure with the reporter. The project
does not guarantee a response or resolution time. If GitHub's private report
option is unavailable, open a public issue asking for a secure contact route
without including exploit details.
