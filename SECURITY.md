# Security policy

## Supported versions

Security fixes are considered for the latest published Heatfall release. Users
should upgrade to the latest release before reporting an issue.

## Report a vulnerability privately

Use GitHub's **Report a vulnerability** feature on the
[Heatfall Security tab](https://github.com/eddiethedean/heatfall/security).
Private vulnerability reporting is enabled for this repository. This sends the
report to repository maintainers without making it public.

Please include the affected Heatfall version, Python and operating system
versions, steps to reproduce, expected and actual behavior, and any known
impact or workaround. Do not include real personal location data. Maintainers
will coordinate a fix and disclosure with the reporter; no response or fix
timeline is guaranteed.

If GitHub's private reporting option is unavailable to you, open a public issue
asking for a secure contact route. Do not include exploit details or sensitive
information in that issue.
