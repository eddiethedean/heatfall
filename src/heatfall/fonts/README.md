# Bundled legend fonts

Unmodified DejaVu Sans Regular and Bold from the official
[DejaVu Fonts 2.37 release](https://github.com/dejavu-fonts/dejavu-fonts/releases/tag/version_2_37).
The archive SHA-256 is
`fa9ca4d13871dd122f61258a80d01751d603b4d3ee14095d65453b4e846e17d7`.

These fonts ensure Pillow legend sizes and weights work consistently without
installing system fonts. The accompanying LICENSE includes the copyright and
redistribution terms. Custom fonts still take precedence when available.
